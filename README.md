# PicMe

PicMe is an agent-guided animated pixel art web app. It runs entirely in the
browser — no backend — and lets you draw pixel art manually, manage animation
frames, and collaborate with an AI agent that asks questions, suggests ideas,
and paints the canvas in real time. Finished animations can be exported as GIF
or as a sprite sheet.

The agent connects to any OpenAI-compatible LLM provider (built-in support for
DeepInfra, OpenAI, and Gemini, plus a custom provider option). API keys are
stored only in the browser.
